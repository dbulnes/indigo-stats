# Clothing panel alternatives

**Static mockups only. Illustrative UI · synthetic results.** No application, backend, provider, or packaging behavior is changed. No provider calls were made. Controls and disclosures are drawings, not interactive elements.

| Concept | Strength | Tradeoff |
| --- | --- | --- |
| **A — Day cards (recommended)** | See all three periods immediately; consistent five-group rhythm; details stay out of the way. | Cards stack on narrow screens. |
| **B — Period focus** | Lowest cognitive load; natural mobile layout; one expanded ranking demonstrates progressive detail. | Switching tabs hides the other periods. |
| **C — Comparison grid** | Fastest cross-period comparison; minimal repeated labels. | Densest option; requires horizontal scrolling with sticky group labels or a separate mobile presentation. |

- `a-day-cards.svg` — 1000 × 900.
- `b-period-focus.svg` — 1000 × 900; includes a narrow-screen preview.
- `c-comparison-grid.svg` — 1000 × 900.

All concepts use the existing slate background, lavender emphasis, mint status accents and restrained borders. Preferences compare alternatives **within each group**, assuming appropriate other layers. Highest-ranked items are not a guaranteed coherent outfit. Accessory percentages are independent estimated usefulness, not measured comfort or protection.

For any approved direction: retain the existing provider/cache/stale/error/busy/cooldown behavior; saved results retain their generation provider and weather snapshot. Only Generate can spend credits; opening, refreshing, changing periods and saving provider settings never generate. Usage examples are synthetic provider-reported input/output token counts, not prices. Setup stays secondary and never asks for keys in the dashboard.

The closed methodology disclosure would retain activity and layer assumptions, source timestamps, feels-like weather, forecast/current-observation distinctions, AI guidance limitations, caching and privacy details. The illustrated default assumes light outdoor activity and average temperature sensitivity.
